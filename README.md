# 山外集

一个基于 Vue 3 + TypeScript 的电商后台管理系统，包含 RBAC 权限、商品管理与数据可视化大屏。

## 功能

- **登录鉴权**：token 持久化、路由守卫、登录后回跳原页面
- **权限管理**：用户 / 角色 / 菜单，RBAC 模型
- **动态路由**：登录后按后端返回的权限过滤路由，未授权菜单不渲染
- **按钮级权限**：`v-has` 指令，无权限按钮直接移除
- **商品管理**：品牌、属性（三级分类）、SPU、SKU 的增删改查
- **数据大屏**：1920×1080 等比适配，8 个图表联动展示
- **首页仪表盘**：统计卡片、趋势图、品牌占比、最新商品

## 技术栈

| 分类 | 技术 |
| --- | --- |
| 框架 | Vue 3.5（`<script setup>`） |
| 构建 | Vite 8 |
| 语言 | TypeScript 6 |
| UI | Element Plus 2.14 |
| 状态 | Pinia 4 |
| 路由 | Vue Router 5（hash 模式） |
| 图表 | ECharts 6 |
| 样式 | Sass / SCSS |
